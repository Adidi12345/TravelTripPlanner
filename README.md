# Travel Trip Planner

Java project demonstrating the Builder Design Pattern.

## Project Description

Travel Trip Planner creates complete travel plans using the Builder Design Pattern.

Each travel trip contains:
- Destination
- Number of days
- Hotel
- Transport
- Food plan
- Activities
- Budget

## Builders

### BudgetTripBuilder
Creates an affordable travel plan with budget-friendly options.

### LuxuryTripBuilder
Creates a luxury travel plan with premium options.

## Technologies

- Java
- JDK 17+
- Builder Design Pattern
